The file `log.nmea` is a public UAV GPS recording by Andrew Tridgell, saved on 27 March 2011.

Source: https://www.samba.org/tridge/UAV/logs/log.nmea

It is a real flight log. The receiver reports no fix, ordinary GPS, and DGPS. It does not report RTK, and it does not include a second antenna or a heading. The heading check is not run on this file.
